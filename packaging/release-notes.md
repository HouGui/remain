REMAIN assembles project PDFs, analyzes configurable Excel KPIs, and exports
printable HTML summaries. It supports optional groups and categories, KPI class
breakdowns, and English, German, and French interfaces.

Choose the package matching your operating system and processor:

- Linux x86-64: Debian/Ubuntu `.deb` or portable `.tar.gz`.
- Windows x86-64: `setup.exe` installer.
- macOS Apple silicon: `aarch64.dmg`.

Each package includes the offline user guide and Rust API reference.
`SHA256SUMS` lists SHA-256 checksums for all packages.

Read the [installation guide](https://hougui.github.io/remain/installation.html)
for system requirements, then [try the demo](https://hougui.github.io/remain/tutorials.html#try-the-demo).
The [Rust API reference](https://hougui.github.io/remain/api/) is also available online.

Windows packages are unsigned. macOS packages are ad hoc signed and are not
Apple-notarized; operating-system publisher warnings may appear.
